# Cover Letters

Create cover letters only for suitable applications where the JD benefits from a short targeted note.

Rules:

- Match the JD without inventing experience.
- Reference only verified experience from [[../Master Resume|Master Resume]].
- Keep it concise.
- Avoid generic claims.
- Link the final cover letter from [[../Applied Jobs|Applied Jobs]].

Naming:

```text
YYYY-MM-DD Company - Job Title.md
```
