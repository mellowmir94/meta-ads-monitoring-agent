# Resume Versions

Create a resume version only when the JD decision is `Strong Apply` or `Apply`.

Rules:

- Use [[../Master Resume|Master Resume]] as the only source of truth.
- No fake tools, years, companies, certifications, achievements, or seniority.
- Reorder sections based on JD relevance.
- Emphasize matching tools, projects, and achievements only when verified.
- Add truthful ATS keywords.
- Remove or reduce irrelevant content.
- ATS-safe format only: no tables, graphics, columns, icons, or decorative formatting.
- Use standard headings and bullet points.
- Use measurable impact only where supported.

Naming:

```text
YYYY-MM-DD Company - Job Title.md
```
